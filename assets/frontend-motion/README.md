# فرانت‌اند در حرکت

یک موشن‌گرافیک حدوداً ۷۳ ثانیه‌ای و فارسی دربارهٔ فرانت‌اند، که خودش فقط با HTML، CSS و JavaScript ساخته شده است.

| فایل | کاربرد |
| --- | --- |
| [`index.html`](index.html) | نسخهٔ تعاملی: پخش و توقف، رفتن به هر صحنه و جابه‌جایی روی خط زمان |
| [`frontend-motion.mp4`](frontend-motion.mp4) | خروجی ویدیویی ۱۹۲۰×۱۰۸۰ با ۳۰ فریم بر ثانیه |
| [`render.mjs`](render.mjs) | ساخت دوبارهٔ ویدیو یا عکس از هر لحظه |

## صحنه‌ها

1. **مقدمه**: فرانت‌اند یعنی هر چیزی که کاربر در مرورگر می‌بیند و لمس می‌کند.
2. **HTML، ساختار**: کد تایپ می‌شود و صفحهٔ بدون استایل، عنصر به عنصر ظاهر می‌شود.
3. **CSS، ظاهر**: هر قاعده‌ای که کامل می‌شود همان لحظه روی صفحه اثر می‌گذارد.
4. **JavaScript، رفتار**: یک شنوندهٔ کلیک، شمارندهٔ دکمه را بالا می‌برد.
5. **مسیر رندر**: JavaScript ← Style ← Layout ← Paint ← Composite در بودجهٔ ۱۶٫۷ میلی‌ثانیه‌ای هر فریم.
6. **کامپوننت‌ها**: صفحه به `Header`، `Hero` و `Card` تقسیم می‌شود.
7. **واکنش‌گرا**: با یک container query، کارت‌ها در عرض ۳۶۰ پیکسل زیر هم می‌روند.
8. **کیفیت**: سه معیار LCP، INP و CLS و چند نکتهٔ دسترس‌پذیری.
9. **جمع‌بندی**: ساختار + ظاهر + رفتار.

## اجرا

فایل `index.html` را در مرورگر باز کنید. فونت‌ها (Lalezar، Vazirmatn و JetBrains Mono) از Google Fonts بارگذاری می‌شوند. کلید Space پخش را متوقف یا شروع می‌کند. اگر سیستم روی «کاهش حرکت» تنظیم شده باشد، پخش خودکار شروع نمی‌شود.

## ساخت دوبارهٔ ویدیو

به Node، Playwright (Chromium) و ffmpeg با libx264 نیاز است:

```bash
node render.mjs                      # frontend-motion.mp4 در 1920x1080
node render.mjs --stills 9,30,65     # عکس از ثانیه‌های مشخص
node render.mjs --fps 24 --scale 1   # 1280x720 با 24 فریم بر ثانیه
```

همهٔ انیمیشن‌ها تابعی از زمان هستند و صفحه تابع `window.__motion.seek(t)` را در اختیار می‌گذارد. برای همین هر فریم ویدیو دقیقاً در زمان خودش ساخته می‌شود و به ضبط هم‌زمان صفحه وابسته نیست.
