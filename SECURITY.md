# Security Policy

## Reporting

Do not open a public issue containing credentials, API tokens, private keys,
subscription URLs, production IP inventories, customer data, or unredacted logs.

For a documentation safety problem, open a minimal public issue with sanitized
evidence. For a vulnerability in a referenced upstream project, report it through
that project's security process; VPNOpsNyx does not own third-party code.

## Supported Documentation

Security corrections are accepted for the current `main` branch and latest release.
Older documentation snapshots may reference superseded upstream behavior.

## Scope

VPNOpsNyx is an operational knowledge skill. It does not distribute a VPN core,
panel binary, hosted service, credential store, or private infrastructure inventory.
